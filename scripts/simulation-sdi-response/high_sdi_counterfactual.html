Aim

This analysis tests whether lower-SDI attention-burden alignment is compatible with a High-SDI transfer null. The counterfactual preserves each sliding window’s observed attention sparsity and inequality, then keeps simulated attention allocations closest to the observed High SDI attention-burden concentration index.

The candidate generator uses a proposal mixture. One component assigns observed nonzero attention scores fully at random; the other components assign the same observed scores to randomly selected conditions with noisy High-SDI rank alignment. The proposal mixture is used to explore enough High-SDI-aligned allocations for calibration; kept allocations are selected by closeness to the observed High SDI concentration index.

The active and reversed metrics are calibrated in separate simulation runs. The active ribbon keeps allocations closest to observed High SDI attention-burden concentration index; the reversed ribbon keeps allocations closest to observed High SDI reversed concentration index.

COVID-19 is excluded before building observed and simulated windows so a single pandemic-era condition does not dominate the range of possible permutations.

The all-time sensitivity uses the all-time attention score distribution and evaluates it against each burden year.

Calibration check

All-time attention sensitivity

This sensitivity repeats the counterfactual using all-time GWAS attention scores and each year of DALYs. It asks whether the accumulated GWAS condition canon is narrower than a generic High-SDI-calibrated canon across the burden history. Because the all-time attention distribution is dense and highly unequal, calibration warnings should be checked before placing strong weight on these ribbons under the default candidate count.
